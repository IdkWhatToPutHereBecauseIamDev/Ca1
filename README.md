**Ca1** is a lightweight, local-first AI assistant built entirely on Apple Shortcuts.  
It runs 100% on your device, responds instantly, and integrates directly with macOS/iOS automation.

No cloud. No external servers. Just a fast, personal assistant that feels like part of your system.

---

## ✦ Features

| Feature | Description |
|--------|-------------|
| Local Execution | Everything runs on-device through Apple Shortcuts. No external API calls. |
| Instant Responses | Zero network delay — Ca1 answers immediately. |
| Voice Support | Can speak and listen through macOS/iOS. |
| Canvas Output | Supports a live Shortcut Canvas for visual responses. |
| Command System | Built-in commands for debugging, history, and control. |
| Single-User Design | Ca1 is meant to be your assistant — personal, private, and always-on. |

---

## ✦ Commands

| Command | Purpose |
|---------|---------|
| `.history` | Repeats your previous messages. Useful for debugging or recalling past interactions.

## ✦ Installation

1. Download the latest Ca1 Shortcut  
   https://github.com/IdkWhatToPutHereBecauseIamDev/Ca1/releases

2. Import into Apple Shortcuts  
   - Open the `.shortcut` file  
   - Allow untrusted shortcuts if required  
   - Add Ca1 to your Dock, Menu Bar, or Automation triggers

3. Grant Permissions  
   Ca1 may request:  
   - Speech recognition  
   - Microphone access  
   - File access  
   - Running scripts

4. Run Ca1  
   Trigger it from:  
   - Siri  
   - Dock  
   - Menu Bar  
   - Keyboard shortcut  
   - Automations  
   - Inside other shortcuts

Ca1 will immediately begin responding locally.
